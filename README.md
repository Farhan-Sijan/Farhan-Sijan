## Selected projects

### [Courier Management System · Rider Module](https://github.com/Farhan-Sijan/WebTech-Fall-2026-27/tree/main/Courier-Management-System/rider)

`HTML` `CSS` `JavaScript` · University team project

My module follows a rider through a delivery. The rider opens an assigned parcel, checks the receiver’s details, and fills out a status update. The frontend checks that the form includes a tracking ID, a delivery status, an OTP, and a proof photo or signature.

[Explore the rider screens](https://github.com/Farhan-Sijan/WebTech-Fall-2026-27/tree/main/Courier-Management-System/rider/Html) · [Read the validation code](https://github.com/Farhan-Sijan/WebTech-Fall-2026-27/blob/main/Courier-Management-System/rider/JS/rider-update-status.js)

### [Restaurant Management System](https://github.com/Farhan-Sijan/Restaurant-Management-System)

`C#` `.NET Framework` `Windows Forms` `SQL Server` · Three-person team project

I worked with two teammates on a desktop application for restaurant staff and customers. Signing in opens the dashboard for that user’s role. The application includes menu management, customer orders, and invoices.

[Explore the Windows Forms code](https://github.com/Farhan-Sijan/Restaurant-Management-System/tree/main/Login) · [View the database script](https://github.com/Farhan-Sijan/Restaurant-Management-System/blob/main/DataBase/RestaurantDatabaseScript.sql)
