## Selected projects

### [🚚 Courier Management System · Rider Module](https://github.com/Farhan-Sijan/WebTech-Fall-2026-27/tree/main/Courier-Management-System/rider)

`HTML` `CSS` `JavaScript` `PHP` `MySQL` · University team project

- **Frontend · Complete** — I built the screens a rider uses to sign in, view assigned parcels, check delivery details, and fill out a status update.
- **Form validation** — The JavaScript checks for a tracking ID, delivery status, OTP, and an attached proof photo or signature.
- **Backend · In progress** — I’m building the server-side part of the rider module with PHP and MySQL.

### [🍽️ Restaurant Management System](https://github.com/Farhan-Sijan/Restaurant-Management-System)

`C#` `.NET Framework` `Windows Forms` `SQL Server` · Three-person team project

- **Role-based dashboards** — My two teammates and I built a desktop app that opens a different dashboard for admins, employees, and customers after sign-in.
- **Restaurant operations** — The app connects menu management, customer orders, and invoices to a SQL Server database.
